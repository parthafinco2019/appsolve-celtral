# Activepieces MCP Bridge Server (Claude Desktop & Cursor)

Production Model Context Protocol (MCP) bridge server connecting Anthropic Claude Desktop and Cursor Composer IDE to Activepieces automations.

## 🚀 Quick Setup

1. Clone or download this repository.
2. Install dependencies & build:
```bash
npm install
npm run build
```
3. Configure `claude_desktop_config.json`:
   - Windows: `%APPDATA%\Claude\claude_desktop_config.json`
   - macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
4. Copy the JSON snippet from `claude_desktop_config.json` into your Claude configuration.
5. Restart Claude Desktop and start automating workflows directly from AI chat!
